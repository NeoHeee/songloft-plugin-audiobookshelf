# Songloft Audiobookshelf Plugin

将 Audiobookshelf 有声书接入 Songloft。主模式通过 MIoT 外部搜索直接播放，不向 Songloft 曲库写入歌曲；导入与增量同步保留为兼容模式。

## v0.6.0 合并测试版

本版合并原计划 v0.5.0 的 M4B/章节能力和 v0.6.0 的语音点播体验：

- 读取 Audiobookshelf 返回的 M4B 内嵌章节
- 支持“书名 + 第 N 章”及“书名 + 章节名”
- 搜索测试与日志显示章节、全书起点及文件内偏移
- 支持系列名与“第 N 部 / 第 N 卷 / 第 N 册”匹配
- 支持“下一集”“上一集”，按插件最近一次直接播放记录切换
- 支持“最近添加”“正在收听”“我的收藏”等分类点播
- 书名、作者、演播者、系列名、副标题综合排序
- 新增默认点播策略：优先继续收听 / 默认从头播放
- 保留中文数字、阿拉伯数字、零填充集数匹配
- 保留 MIoT 不入库直接播放及 Songloft 兼容导入模式
- 默认服务器地址：`http://192.168.1.1:13378`

## 安装与设置

1. 在 Audiobookshelf“设置 → API 密钥”中创建密钥，代理平时收听的普通用户。
2. 安装并启用本插件，填写局域网地址、API 密钥并选择有声书书库。
3. 选择默认点播方式：“优先继续收听”或“默认从头播放”。
4. 安装支持搜索源注册的新版 MIoT 插件。
5. 在 MIoT“外部搜索”中选择“Audiobookshelf 有声书”。
6. 开启外部搜索和“不入库直接播放”。

建议测试这些说法：

- `播放 明朝那些事儿`
- `继续播放 明朝那些事儿`
- `播放 明朝那些事儿 第五章`
- `播放 鬼吹灯 第二部`
- `播放下一集` / `播放上一集`
- `播放最近添加的有声书`
- `继续收听`
- `播放我的收藏`

> Songloft 服务端和智能音箱都必须能够访问 Audiobookshelf 的局域网地址。

## 当前边界

- Songloft V2.11.0 插件 HTTP 接口会将响应完整缓存在内存后返回，不能安全承载数小时音频的流式代理。因此本版仍使用 Audiobookshelf 的 `token` 查询参数直链。请仅在可信局域网使用，并配置普通用户、最小权限的独立 API 密钥。
- 插件现已能计算 M4B 章节或续播位置在音频文件内的准确秒数，并在搜索结果中返回 `start_position`。MIoT/音箱当前仍未提供起始秒数控制，因此设备可能从该文件开头播放；这属于宿主能力边界，不代表章节识别失败。
- “下一集/上一集”依据本插件最近一次直接播放记录工作；重装插件或清除配置后需先正常点播一本书。
- “我的收藏”依赖当前 Audiobookshelf 版本在书库条目或用户进度中返回收藏标记；若服务器未返回该字段，会提示没有匹配内容。

## 兼容导入模式

仍支持一本书对应一个 Songloft 歌单、重复导入去重、单本检查更新及整个书库增量同步。
